# Creating hierarchical symbols

Expose input and output ports using `N`.
Then, file -> new symbol.

Draw a picture of what we want, use some small lines for pins.

Edit -> add pins (make sure to use exact same name as nets on schematic)

Edit -> Edit attributes -> change to cell mode

Save as a symbol

Import as regular component

Use `{value}` for parameterized components then in top level right click -> SpiceLine: `value = xxx`.
